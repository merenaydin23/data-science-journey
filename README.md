## 📖 About

This repository documents my journey through **Jose Portilla's Python for Data Science and Machine Learning Bootcamp** on Udemy. Each folder contains Jupyter notebooks with my personal notes, exercises, and additional practice with real-world datasets from Kaggle.

> Every notebook includes a short summary at the top explaining what I learned — written in my own words.
